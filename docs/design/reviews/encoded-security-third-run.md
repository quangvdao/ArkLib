## Fidelity addendum: missing middle-to-coarse charge inequality

**Disposition: material S2 acceptance gap (P2 coverage), not a flaw in the two proved security bounds.** The contract's MUST 1 displays a *chain* from accepted bad-event probability to actual joint distinct-key charge and then to `max_i ε_i · E[|D_A|] + Σ_i ε_i` (`interaction-security-third-run-contract.md:66–90`). S2 asks for “actual log/charge transport and the same security inequality, charging each distinct encoded key once” (`:153–160`). On that conservative reading, the exported S2 theorem family should show

`E[external image-weighted distinct charge of the actual joint run] ≤ (max_i ε_i) · E[distinct external adversary keys] + Σ_i ε_i`.

At committed source `EncodedSecurityEvent.lean:132–195`, the sharp theorem proves `Pr[bad] ≤ E[external joint weighted charge]`. The separate theorem at `:200–247` proves `Pr[bad] ≤ coarse adversary-count bound`. **Those two statements do not imply the displayed cost-to-coarse inequality**: a probability can lie below two incomparable bounds. Therefore the current source supports both useful probability bounds but not the full S2 resource chain as an exported conclusion. The missing inequality is a release/documentation gate if S2 is advertised as the same complete inequality; it does not block merging a clearly labeled partial sharp/coarse theorem slice.

The missing bound appears genuinely derivable without a new security assumption. Strict decoding makes image keys unique, off-image weights are zero, and `routeProgram_nativeLog` relates the native log to the external image log on every actual outcome; a reverse direction to `freshImageCharge_le` should give **equality** of weighted native and external charges (the current `EncodedWeighted.lean:57–69` only exports `≤`). Compose that equality with the common-fibre cost equality and the native stopped resource theorem `expectedStoppedFreshCharge_le_actualRounds` (`StateRestorationStoppedBudget.lean:98–138`), `expectedStoppedJointAdversaryKeys_eq_expectedAdversaryFreshKeys` (`:299–346`), the existing encoded adversary count transport (`EncodedSecurity.lean:75–98`), and the external distinct-key count inequality (`EncodedLog.lean:210–245`). Alternatively prove the pathwise external log decomposition directly: distinct image keys from the adversary cost at most max-error times all adversary distinct external keys; reached verifier image keys cost at most the round-error sum, even when already cached. In either route, retain returned failures and the same actual joint cache. No permission or new modeling choice is needed to add the corollary.
