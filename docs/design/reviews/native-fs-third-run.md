## Follow-up, not a merge blocker for this slice

The contract explicitly asks that uniform errors yield a `(Q+k)ε` **security probability** headline. The code exports the generic Q probability theorem and uniform query-charge theorem separately; their composition gives this inequality but no named generic probability corollary. Sumcheck already exports the direct `(Q+n)fieldError` probability statement. A short generic corollary would improve the API, but the mathematics is present and this does not block the native PR. The full MUST 2 claim must remain unadvertised until the finite legacy correspondence and #848 premise discharge are independently reviewed.
