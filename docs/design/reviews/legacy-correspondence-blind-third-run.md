The subsequent completion's queries are outside this expected-cardinality term; their per-round cost is the additive error sum. All probability statements remain valid with extended-real errors; if the right side is at least one, they provide no nontrivial security estimate.

## Actionable semantic limits and unresolved links

1. **No end-to-end probability inequality appears in the inspected modules.** The native error theorem, fixed-table simulation/derivation equalities, game-unrolling equality, and query-bound lemmas are separate statements. To infer a bound on the instantiated `coinKSExperimentProb` for a source prover, one must still identify `init` with the pushforward of the sampled native table under `nativeTableToLegacy`, carry the logged native event through the path/transcript correspondence, supply `Salt = PUnit` and the extractor laws, and combine the expected-key inequality with the error bound. `nativeFiniteLegacyInit` is generic in `pSpec` and `tableToImpl`; its declaration does not itself assert that distributional bridge. The smallest useful public bridge would state that concrete game probability inequality (or an exact game equality followed by the native bound) with all these choices explicit.
2. **Sampling law is a necessary part of any bridge.** `nativeLegacyTableEquiv` proves a bijection of function tables. The displayed code does not state that sampling a legacy table directly, if attempted, has the pushforward law of `$ᵗ (Table Input PUnit rounds)`. A safe bridge can define `init` as `nativeTableToLegacy rounds <$> $ᵗ (Table Input PUnit rounds)` and prove against that exact initializer. Whether a separately constructed legacy table sampler has the same law depends on its challenge `SampleableType` instances; this was not established by the inspected declarations.
3. **Do not read the bound as unconditional knowledge soundness.** The chosen backward extractor receives a total `seed` from any output witness `W` and full path to a terminal-state witness, and the initial/terminal relation laws are hypotheses. In the empty or incompatible relation cases, the bad event or hypotheses can be vacuous. A concrete application must exhibit the seed and laws and show the error expression is small.
4. **The legacy model here has unit salts and message-prefix keys.** The key equivalence and source-prover simulation are for `PUnit`, while the native premise theorem permits arbitrary `Salt`. A claim about nontrivial salts, challenge-history keys, or additional oracle access needs further definitions and proofs. The source base oracle `ofPFunctor 0` is empty, so this instantiation gives the prover no extra non-hash base oracle; its other access is `unifSpec` coins.
